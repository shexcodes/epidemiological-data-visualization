# Data — Python visualization part

These input files are **course-provided** and are not committed to the
repository (they are ignored via `.gitignore`). Place the following files in
this folder before running `data_visualization_part2.ipynb`:

| File | Used in | Description |
|------|---------|-------------|
| `10_project_data_annotation.csv` | Exercise 1, 2 | Genomic annotations — rows of `type` (`exon`/`transcript`), `start`, `stop`, `strand` (`+`/`-`). |
| `10_project_data_signals.csv` | Exercise 1, 2 | Signals of four RNA-binding proteins in columns `P1`–`P4` (one row per genomic position). |
| `10_project_data_scatter.csv` | Exercise 2 | Scatter-plot data with columns `x1`, `x2`. |
| `10_project_data_barplot.csv` | Exercise 2 | Grouped bar-plot data. |
| `10_project_data_dna_sequences.txt` | Exercise 3 | One DNA sequence per line. |

> Note: the assignment brief refers to `10_project_data_annotations.csv`
> (plural) while the notebook reads `10_project_data_annotation.csv`
> (singular). Use whichever name matches your copy and keep the notebook in
> sync.
